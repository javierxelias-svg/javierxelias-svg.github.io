About

Industrial Design taught me that form has to earn its function. I build the same way now, in software: autonomous multi-agent automations, a full business operating system, desktop apps, a knowledge base a model maintains as its own memory.

I build like it has to run without me watching: preflight checks, crash handling, a human tap before anything real happens. Selected Work

Featured · the system you're reading

The workspace that wrote this application.

A workspace I architected inside Claude Code to keep myself disciplined: custom slash commands, a verification-gate doctrine, file-based memory that survives a session reset, and a spec → plan → build → verify → ship pipeline every deliverable moves through.

The non-obvious decision: it forbids the sentence "this should work." Nothing is done because it looks done, only when it ran and left a receipt. Honesty is enforced by the machine, not by willpower.

This résumé, the essays, and this page were produced by this system. You're reading its output.

XPT OS

An autonomous lead engine that runs without me: three cooperating agents search 14+ fragmented sources weekly, score each lead against a weighted rubric with hard vetoes, dedupe against a persistent ledger so nothing surfaces twice, and draft personalized outreach to Telegram.

The cloud sandbox blocks outbound network calls, so I used a git commit as the message queue to get work off the box.

Live · 11 verified net-new leads · outreach auto-drafting weekly
/ 02

Web OS

A web-design business encoded as software: a five-stage system (source → design → outreach → CRM → close) that finds businesses with weak sites, produces $10K-quality builds, and runs the sale. ~2,750 lines of Python across 21 scripts plus a Next.js build starter.

The hard part wasn't scraping, it was encoding judgment: which leads are worth it, an explicit anti-slop design bar, and a verify-before-send gate added after an early run bounced ~17%.

v1 · strategy since pivoted on its own retrospective
/ 03

ELiaS

A 9-agent personal AI operating system, built the way I'd want it if something real depended on it. ~9,700 lines: a shared resilience layer (preflight that exits clean instead of crash-looping, crash wrapper with alerting, Keychain secret fetch), a 4-provider LLM failover cascade, and a dead-man's switch that alerts from off the machine so a dead Mac still raises an alarm.

A hard rule: machine-written knowledge is quarantined from anything the system tells me about myself. Every real-world action needs a human tap.

Dormant · the resilience rules I now build by were extracted from how this one failed
/ 04

2nd Brain OS

A knowledge base a language model maintains as its own memory: an Obsidian vault where Claude Code is librarian and writer, with a three-tier context budget and a hand-written task router that answers any question in a capped number of reads.

A ground-truth file the model is forbidden to exceed, and autonomous writes tagged unverified, so machine claims stay separable from human fact. 176 agent-authored pages, nightly backup.

Knowledge layer live and compounding · scheduled-agent layer down and documented as such
/ 05

Inventory System

The first thing I built to help someone else. A first-time founder starting a glass-fabrication shop asked me to build his inventory system with Claude Code, so I did, for free. Google Sheets, two tabs: a master item database and a daily movements log. Scan an item ID, the sheet pulls its details, log stock in or out, and the on-hand count updates itself.

On-hand quantity is never typed, it's derived from the movement ledger, so the count can't disagree with its own history. Formulas over scripts on purpose: every rule is visible in the cell, so someone non-technical can own it without me around.

Built unpaid, to help a first-time founder get off the ground
FrecuencIA OS content OS

A content-creation operating system I run for myself. A context-engineered Claude Code workspace that boots a full session with one command, plus a content engine that turns a voice memo into ready-to-post pieces without touching my voice: Claude transcribes, I write.

Live for its owner · building a personal presence from zero, in public

XPRST macOS · Electron

A macOS dictation app that never steals focus. Hit a hotkey anywhere, speak, and the transcript lands on your clipboard without the app you're in ever knowing it happened. Whisper via Groq, 3,157 lines. The hard part was Electron window management: a pill UI built to be un-focusable and click-through.

Personal daily driver · stable · not productized
